## Selected work

### [EcoMRI](https://github.com/DevanshSinghBais/ecomri)

An environmental monitoring prototype with a typed tRPC/Express API, map and trend views, and evidence-led anomaly investigations. **All station readings are simulated demo data.**

_TypeScript · React · tRPC · Express_

### [StudyPilot](https://github.com/DevanshSinghBais/StudyPilot)

A Python/Gradio learning agent that routes study tasks to tools for calculations, local-note search, study plans, quizzes, and data analysis.

_Python · Gradio · LLM function calling · NumPy_

### [GitHub Repo Explainer](https://github.com/DevanshSinghBais/GitHub-Repo-Explainer)

Fetches a repository README through the GitHub REST API and streams a beginner-friendly explanation generated with Gemini.

_Python · GitHub REST API · Gemini_

### [Pneumonia Detection](https://github.com/DevanshSinghBais/Pneumonia_Detection)

A TensorFlow/Keras baseline that classifies chest X-rays from resized, grayscale images. The dataset is not included in the repository.

_Python · TensorFlow/Keras · NumPy · scikit-learn_

- **Languages:** Python · TypeScript · C++
- **AI and data:** LLM APIs · function calling · TensorFlow/Keras · NumPy · scikit-learn
- **Web and APIs:** React · Gradio · Express · tRPC · GitHub REST API
